# yuramon-web

This is the repository for my personal website/project, hosted via GitHub Pages with a custom domain.

## Live Demo
You can visit the site here: **[https://www.yuramon.com](https://www.yuramon.com)**

## Overview
- **Purpose**: (Example: Portfolio website / Creative showcase)
- **Tech Stack**: HTML5, CSS3, JavaScript
- **Hosting**: GitHub Pages
- **Domain Management**: Squarespace (Custom DNS configuration)

## Features
- Fully responsive design (Mobile friendly)
- Clean and minimal UI
- Optimized for fast loading

## Setup & Maintenance
This site is automatically deployed from the `main` branch. 
Custom domain settings are managed via:
- **A Records**: Pointed to GitHub Pages IPs (185.199.108.153, etc.)
- **CNAME**: Pointed to `yuramon-create.github.io`
